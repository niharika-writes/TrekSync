# Trekking-Management-Application
A Flask-based web application for managing trekking.
The following technologies and tools were used in the development of this project:  
 Flask: Used as the lightweight backend web framework to handle server-side logic, routing, and 
requests.  
 Flask-SQLAlchemy: Used as the ORM (Object-Relational Mapping) to design and query the 
SQLite database.  
 Flask-Login: Implemented for secure session management, user tracking, and authentication 
states.  
 SQLite: Used as the relational database engine for storing application data.  
 Jinja2: Used for dynamic rendering of server-side data inside HTML templates.  
 HTML, CSS, Bootstrap 5: Used for crafting a premium, responsive, and mobile-friendly user 
interface.  
 Bootstrap Icons: Used for descriptive navigation menu shortcuts and action button styling. 
 Werkzeug Security: Implemented for safe, one-way password hashing and validation.
